# Grazalema Resiliente - KarstAlerta 🚀🏔️

[![License: MIT](https://shields.io)](https://opensource.org)
[![Status: Prototype](https://shields.io)

**Grazalema Resiliente** es una plataforma de ciencia ciudadana y código abierto co-diseñada para anticipar riesgos meteorológicos y geológicos en entornos kársticos. El sistema busca transformar teléfonos móviles comerciales en una malla de alerta temprana al servicio de la seguridad comunitaria.

🌍 **Live Prototype:** [https://github.io](https://lmgch.github.io/grazalema-resiliente/)

---

## 📖 English Abstract (Global Replication)
This is an open-source, community-driven early warning system tailored for karst geological environments prone to heavy rainfall and flash flooding. The core architecture is completely modular. **You can fork this repository and adapt the site to map and monitor climate-driven or seismic risks in your own local community.**

---

## 🛠️ Tech Stack & Integrations
- **Frontend:** HTML5, CSS3 (Responsive Design), JavaScript (Vanilla/ES6).
- **APIs Integradas:** 
  - [Open-Meteo API](https://open-meteo.com) (Real-time weather & atmospheric variables).
  - [EMSC (Euro-Mediterranean Seismological Centre) API](https://emsc-csem.org) (Real-time seismic data feed).

## 🗺️ Site Map / Estructura del Sitio
La aplicación web se organiza de forma modular para maximizar la accesibilidad del usuario:
- `index.html` (Home) -> Panel principal de estado de la red y manifiesto del proyecto.
- `aula-karstica/` -> Sección pedagógica sobre el relieve kárstico y el fenómeno del "Reventón".
- `datos-en-vivo/` -> Dashboard interactivo de monitorización sísmica y meteorológica.
- `colaborar/` -> Formulario de inscripción para el experimento de sensorización celular y entornos de desarrollo.
